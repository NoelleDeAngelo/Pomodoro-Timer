# Pomodoro Timer

A customizable Pomodoro timer built with Next.js and deployed on Vercel. This is a work in progress, created to give more control over focus sessions by allowing users to adjust times and manage intervals on the fly.

Live Demo: [Vercel App](https://pomodoro-timer-six-hazel.vercel.app/)


## Features

**Cycle Structure:** 5 sets total → 4 × (Pomodoro → Short Break), then (Pomodoro → Long Break).

**Defaults:** 20 min Pomodoro, 5 min Short Break, 15 min Long Break.

**Adjustable:** Modify durations anytime, even while the timer is running.

**Controls:**

- Adjust time of next pomodoro or break.
  
- Add/remove minutes from the current timer.

- Restart current interval.

- Skip to next interval.

- Reset clears all completed intervals and restarts from the beginning.

**Chime Alert:** Plays a chime when each timer ends (can be muted).
